# 📚 자료실 (Resources)

이 폴더는 순장님들께 제공할 추가 자료들을 보관하는 공간입니다.

## 📋 현재 제공 중인 자료

- **순모임 10계명.jpg**: 건강한 순모임을 위한 10가지 원칙
- **순모임ABC.pdf**: 순모임 운영을 위한 기본 가이드북
- **순원서약서.jpg**: 순원으로서의 다짐과 약속을 담은 서약서

> 💡 이 자료들은 [순모임 콘텐츠 페이지](../soonmoim-contents.html)에서 확인하고 다운로드할 수 있습니다.

## 📁 폴더 구조 (예시)

```
resources/
├── manuals/          # 매뉴얼 및 가이드 문서
├── templates/        # 순모임 템플릿 자료
├── videos/           # 교육 영상 자료
├── worksheets/       # 활동지 및 워크시트
└── tips/             # 팁과 노하우 문서
```

## 📝 자료 추가 가이드

### 1. 파일 명명 규칙
- 날짜 포함: `YYMMDD_파일명.확장자`
- 예: `250107_순모임_가이드.pdf`

### 2. 카테고리별 분류
- 관련 있는 자료끼리 서브 폴더로 정리
- 명확한 폴더명 사용

### 3. 문서 형식
- PDF: 공식 문서, 매뉴얼
- Markdown: 텍스트 가이드
- 이미지: 인포그래픽, 차트
- 동영상: MP4 (또는 링크)

## 🔄 업데이트 프로세스

1. 새 자료를 해당 카테고리 폴더에 추가
2. 메인 페이지(`index.html`)에 링크 추가 또는 업데이트
3. 필요시 별도 페이지 생성 (예: `soonmoim-contents.html`)
